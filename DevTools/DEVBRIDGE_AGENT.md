# Knowledge Framework Dev Bridge Workflow

Run the pure behavioral suite and owner validator after building. Discover the live bridge and query `lan.knowledgeframework` context before game tests. Use read-only commands first and acquire write authority only when required. Reload a validated adapter-only change; use a full restart for gameplay, definitions, Harmony, serialized types, or core changes. For a coordinator-owned sandbox, request `restart request --agent-id <id> --package-id lan.knowledgeframework --readiness game --save-policy none`; attached/live processes require a person or external orchestrator. Discard all cached context, cursors, handles, and leases after transitions.
