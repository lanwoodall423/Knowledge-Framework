# Knowledge Framework Dev Bridge Workflow

Run the pure behavioral suite and owner validator after building. Discover the live bridge and query `lan.knowledgeframework` context before game tests. Use read-only commands first and acquire write authority only when required. Reload a validated adapter-only change; use a full restart for gameplay, definitions, Harmony, serialized types, or core changes. Discard all cached context, cursors, handles, and leases after transitions.
